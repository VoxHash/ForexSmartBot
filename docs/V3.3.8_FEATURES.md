# ForexSmartBot v3.3.8 — Stochastic Kernels

## Overview

v3.3.8 advances the **native performance core** (`fsb_core` **0.6.0**): Stochastic Oscillator (`%K` / `%D`) plus `%K/%D` crossover equity and parallel parameter sweeps. NumPy fallbacks keep the same APIs when the extension is not built.

## Features

### Stochastic Oscillator (`stochastic`)

- Returns `k` (%K) and `d` (%D = SMA of %K)
- `%K = 100 * (close − lowest_low) / (highest_high − lowest_low)` over `k_period`
- Requires `k_period >= 1` and `d_period >= 1`
- Pass the same series for high/low/close when only closes are available

### Stochastic crossover equity / sweep

- `equity_stochastic_crossover` — long/short on `%K` / `%D` crosses (same side logic as SMA crossover)
- `sweep_stochastic_crossover` — parallel grid; rows `[k_period, d_period, final_equity, total_return, max_drawdown]`

## Build

```bash
pip install maturin
cd native/fsb_core && maturin develop --release
python -c "from forexsmartbot.utils.native_indicators import native_status, sweep_stochastic_crossover; import numpy as np; print(native_status()); c=np.linspace(1.1,1.2,200); print(sweep_stochastic_crossover(c,[10,14],[3,5]).shape)"
```
