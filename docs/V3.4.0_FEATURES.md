# ForexSmartBot 3.4.0 — Modern Trading Desk Shell

## Summary

Desktop GUI shell overhaul: persistent left navigation, content stage, and a bottom session strip for equity / P&L / connection — with a unique VoxHash dark palette.

## How `morluto/rea` was used

[`morluto/rea`](https://github.com/morluto/rea) (MIT, TypeScript / MCP reverse-engineering agents, npm `rea-agents`) is **not** a GUI library and is **not** vendored as a dependency or submodule.

It was used as a **methodology reference**: reverse-engineer capability and structure of polished multi-pane desktop UX, then **adapt** those capabilities into this PyQt6 trading app under a compatible license posture (ideas + structure only).

## Layout inspiration (no affiliation)

Spacing and information architecture loosely informed by public write-ups of multi-pane desktop media apps (left library/nav, central stage, dense bottom “now playing” strip), for example:

- [Spotify Newsroom — Desktop redesign (Your Library / Now Playing)](https://newsroom.spotify.com/2023-06-20/spotify-desktop-experience-redesign-your-library-now-playing-views-customize/)
- [IXD@Pratt — Design Critique: Spotify for Desktop](https://ixd.prattsi.org/2024/01/design-critique-spotify-for-desktop/)

**ForexSmartBot is not affiliated with Spotify.** We do not use Spotify trademarks, logos, copyrighted assets, or brand green `#1DB954` as identity. Session-bar metrics map to trading (broker, connection, equity, unrealized P&L, drawdown).
