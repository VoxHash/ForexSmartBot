# ForexSmartBot v3.3.0 — Companion + Strategy Health Dashboard

## Overview

v3.3.0 ships the **Q2 2027 first slice**: a read-only mobile companion API, strategy-health web dashboard on the remote monitor, webhook alerts (GrapheneOS-friendly), and an Android Kotlin scaffold. Desktop PyQt remains the execution host; phones do not hold broker keys.

## Features

### 1. Strategy health web dashboard

`RemoteMonitorServer` serves:

- `GET /api/v1/strategies` — all strategy health + summary
- `GET /api/v1/strategies/<name>` — single strategy
- Dashboard HTML table (status, signals, errors, avg latency, last signal)

Attach a live `StrategyMonitor`:

```python
from forexsmartbot.cloud.remote_monitor import RemoteMonitorServer
from forexsmartbot.monitoring.strategy_monitor import StrategyMonitor

sm = StrategyMonitor()
sm.record_signal("SMA_Crossover", execution_time=1.2)
monitor = RemoteMonitorServer(api_key="YOUR_STRONG_API_KEY", strategy_monitor=sm)
monitor.start()
# Open http://127.0.0.1:8080 and paste the API key
```

### 2. Read-only companion API

Mounted on the remote monitor (and usable standalone via `CompanionAPI`):

| Endpoint | Auth | Purpose |
| --- | --- | --- |
| `GET /api/v1/companion/health` | public | Service + feature flags |
| `GET /api/v1/companion/portfolio` | Bearer / X-API-Key | Balance, equity, positions |
| `GET /api/v1/companion/positions` | yes | Positions only |
| `GET /api/v1/companion/alerts` | yes | Recent alerts |
| `GET /api/v1/companion/strategies` | yes | Strategy health |
| `POST/DELETE /api/v1/companion/devices/webhook` | yes | Register HTTPS webhook |

Control routes are **off by default** (`allow_control=False`).

### 3. Webhook notifier (no Google required)

`WebhookNotifier` posts JSON alerts to registered `https://…` URLs (or `http://127.0.0.1` for local relays). Prefer this on GrapheneOS over FCM.

### 4. Android companion scaffold

Path: `mobile/android-companion/`

- Kotlin + Retrofit/OkHttp client for companion endpoints
- No Firebase / Play Services
- `allowBackup=false`, cleartext only for loopback / emulator
- Read-only UI: base URL + API key → portfolio + strategy summary

Open the folder in Android Studio; point the device at your desktop monitor (USB reverse / LAN HTTPS).

## Security

1. Strong `API_KEY` (16+ chars) for non-loopback binds
2. Companion is read-only unless you explicitly enable control
3. Webhooks require HTTPS (except localhost)
4. Broker credentials stay on the desktop host
