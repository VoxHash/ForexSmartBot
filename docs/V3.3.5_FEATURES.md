# ForexSmartBot v3.3.5 — EMA / MACD Native Kernels

## Overview

v3.3.5 advances the **native performance core** (`fsb_core` **0.4.0**): EMA and MACD indicators plus EMA-crossover and MACD-signal crossover equity kernels with rayon-backed parameter sweeps. NumPy fallbacks keep the same APIs when the extension is not built.

## Features

### EMA (`ema`)

- Seeded with SMA of the first `period` bars; leading values are NaN
- Used by EMA-crossover equity and as the basis for MACD

### MACD (`macd`)

- Returns `macd` (fast EMA − slow EMA), `signal` (EMA of MACD), and `histogram`
- Requires `fast < slow` and all periods ≥ 1

### EMA crossover equity / sweep

- `equity_ema_crossover` — long/short on fast/slow EMA crosses
- `sweep_ema_crossover` — parallel grid; rows `[fast, slow, final_equity, total_return, max_drawdown]`

### MACD crossover equity / sweep

- `equity_macd_crossover` — trade MACD line vs signal crosses
- `sweep_macd` — parallel grid; rows `[fast, slow, signal, final_equity, total_return, max_drawdown]`

## Build

```bash
pip install maturin
cd native/fsb_core && maturin develop --release
python -c "from forexsmartbot.utils.native_indicators import native_status, sweep_macd; import numpy as np; print(native_status()); c=np.linspace(1.1,1.2,200); print(sweep_macd(c,[8,12],[17,26],[5,9]).shape)"
```
