# ForexSmartBot v3.3.6 — fsb-core on PyPI

## Overview

v3.3.6 publishes the optional native extension as a standalone PyPI package **[`fsb-core`](https://pypi.org/project/fsb-core/) 0.4.0**, so users can install accelerated indicators/equity kernels without building from the ForexSmartBot source tree.

## Install

```bash
pip install forexsmartbot==3.3.6
pip install fsb-core==0.4.0   # optional native acceleration
python -c "from forexsmartbot.utils.native_indicators import native_status; print(native_status())"
```

Without `fsb-core`, NumPy fallbacks in `forexsmartbot.utils.native_indicators` keep the same APIs.

## CI

Workflow `.github/workflows/publish-fsb-core.yml` builds manylinux wheels for Python 3.10–3.13 plus an sdist, then publishes on tags `fsb-core-v*.*.*` (Trusted Publisher / OIDC). First **0.4.0** release was uploaded with a one-time API token + twine.
