# ForexSmartBot v3.3.7 — Bollinger Kernels + Multi-Platform Wheels

## Overview

v3.3.7 advances the **native performance core** (`fsb_core` **0.5.0**): Bollinger Bands indicator plus mean-reversion equity/sweep kernels, and broader PyPI wheel coverage (Linux manylinux, Windows x64, macOS arm64/x86_64) for Python 3.10–3.13. NumPy fallbacks keep the same APIs when the extension is not built.

## Features

### Bollinger Bands (`bollinger`)

- Returns `middle` (SMA), `upper`, `lower`
- Sample standard deviation (ddof=1), matching pandas `rolling.std()`
- Requires `period >= 2` and `num_std > 0`

### Bollinger mean-reversion equity / sweep

- `equity_bollinger_mean_reversion` — long on cross up through lower band, short on cross down through upper
- `sweep_bollinger_mean_reversion` — parallel grid; rows `[period, num_std, final_equity, total_return, max_drawdown]`

### Multi-platform publish

- `.github/workflows/publish-fsb-core.yml` builds wheels on `ubuntu-24.04`, `windows-latest`, `macos-14` (aarch64), and `macos-13` (x86_64)

## Build

```bash
pip install maturin
cd native/fsb_core && maturin develop --release
python -c "from forexsmartbot.utils.native_indicators import native_status, sweep_bollinger_mean_reversion; import numpy as np; print(native_status()); c=np.linspace(1.1,1.2,200); print(sweep_bollinger_mean_reversion(c,[10,20],[1.5,2.0]).shape)"
```
