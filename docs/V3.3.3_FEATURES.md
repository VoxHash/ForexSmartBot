# ForexSmartBot v3.3.3 — Native Walk-Forward + Multi-Symbol Workers

## Overview

v3.3.3 advances the **native performance core** (`fsb_core` **0.2.0**): rayon-backed SMA-crossover parameter grid sweeps, walk-forward train/test window sweeps, and multi-symbol equity aggregation workers. PyQt stays on the Python side; NumPy fallbacks keep the same APIs when the extension is not built.

## Features

### Parameter grid sweep (`sweep_sma_crossover`)

- Parallel evaluation of `(fast, slow)` pairs with `fast < slow`
- Each row: `[fast, slow, final_equity, total_return, max_drawdown]`
- Useful for IS optimization steps inside walk-forward

### Walk-forward sweep (`walk_forward_sma_sweep`)

- Helper `walk_forward_windows(n, train_size, test_size, step_size)` builds rolling index windows
- Per window: grid-search on train → freeze best pair → score on test
- Result rows: `[best_fast, best_slow, train_return, test_return, test_final_equity, test_max_dd]`

### Multi-symbol aggregation (`multi_symbol_equity_aggregate`)

- Parallel per-symbol SMA-crossover equity curves
- Weighted (or equal-weight) portfolio equity from normalized symbol returns
- Returns `{"per_symbol": [...], "portfolio": ndarray}`
