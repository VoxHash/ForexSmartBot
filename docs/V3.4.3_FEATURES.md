# ForexSmartBot 3.4.3 Features

## Live (opt-in) Binance mainnet

- **Binance Live** (`BinanceLiveBroker`): HMAC Spot orders against production
  `https://api.binance.com/api`. Requires **all** of:
  - `FSB_LIVE_TRADING=1` (explicit opt-in; construction / connect refuse otherwise)
  - `BINANCE_LIVE_API_KEY` / `BINANCE_LIVE_API_SECRET` (dedicated live keys;
    sandbox `BINANCE_API_*` are never reused)
  - Mainnet host only — Spot Test Network URLs are refused
- Settings → Broker Mode: **Binance Live** (falls back to paper if flag unset)
- Prefer trade-only API keys with withdraw disabled + IP allowlist

## Kill-switch (reuses RiskEngine)

- `RiskEngine.trip_kill_switch` / `evaluate_kill_switch` (daily risk + max drawdown)
- Env force: `FSB_KILL_SWITCH=1` (cannot be cleared in-process)
- UI Stop Trading trips the software kill-switch; Start clears it unless env-forced
- `activate_kill_switch()` stops trading and flattens via `flatten_all()` when available
- Live broker blocks new opens while kill-switch is active; flatten/close still allowed

## Opsec

- Secrets only in local `.env` (see `.env.example` placeholders)
- Logs use `mask_secret` / `redact_mapping` — never echo raw keys
- CI must not set `FSB_LIVE_TRADING`; tests mock the live path only
