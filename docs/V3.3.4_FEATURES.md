# ForexSmartBot v3.3.4 — RSI Mean-Reversion Kernel + Native Wheel CI

## Overview

v3.3.4 advances the **native performance core** (`fsb_core` **0.3.0**): an RSI mean-reversion equity kernel with rayon-backed parameter sweeps, plus optional `maturin` wheel artifacts uploaded from CI. NumPy fallbacks keep the same APIs when the extension is not built.

## Features

### RSI mean-reversion equity (`equity_rsi_mean_reversion`)

- Long when RSI crosses up through `oversold`
- Short when RSI crosses down through `overbought`
- Compact mark-to-market equity loop (native or NumPy)

### Parameter grid sweep (`sweep_rsi_mean_reversion`)

- Parallel evaluation of `(period, oversold, overbought)` triples
- Each row: `[period, oversold, overbought, final_equity, total_return, max_drawdown]`

### CI native wheels

- Workflow job `native-wheels` builds `fsb_core` with `maturin build --release`
- Uploads `fsb-core-wheels` artifacts (14-day retention) for local install / inspection

## Build

```bash
pip install maturin
cd native/fsb_core && maturin develop --release
python -c "from forexsmartbot.utils.native_indicators import native_status, sweep_rsi_mean_reversion; import numpy as np; print(native_status()); c=np.linspace(1.1,1.2,200); print(sweep_rsi_mean_reversion(c,[14],[30],[70]).shape)"
```
