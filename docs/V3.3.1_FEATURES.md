# ForexSmartBot v3.3.1 — Q2 Companion Polish

## Overview

v3.3.1 continues the Q2 companion track: strategy history charts, QR pairing, host approve/reject for high-level actions, Compose Android UI with cert-pinning hooks, and an F-Droid metadata draft.

## Features

### Strategy history charts

- `GET /api/v1/strategies/history` and `GET /api/v1/strategies/<name>/history`
- Companion mirrors under `/api/v1/companion/strategies/.../history`
- Dashboard canvas sparklines (signal count series)
- `StrategyMonitor` history points use ISO timestamps

### QR pairing

1. Host (authenticated): `POST /api/v1/companion/pairing/session` → `qr_text` / `qr_payload`
2. Phone: `POST /api/v1/companion/pairing/redeem` with `pairing_code` (no prior key)
3. Codes expire in 5 minutes and are single-use
4. Dashboard **Create pairing QR** renders the payload

### Approve / reject actions

Phone may `POST /api/v1/companion/actions` with `start_trading` | `stop_trading` | `pause_trading`.
Host lists pending actions and calls `.../approve` (runs registered callback) or `.../reject`.

### Android companion 0.2.0

- Jetpack Compose Material3
- Paste pairing JSON or decode QR from gallery (ZXing — no Play Services)
- Request start/stop (desktop must approve)
- Optional OkHttp certificate pinning (`CERT_PINS` build field and/or pairing `pin_sha256`)
- F-Droid draft: `mobile/android-companion/metadata/dev.voxhash.fsbcompanion.yml`
