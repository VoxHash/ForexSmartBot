# ForexSmartBot 3.4.4 Features

## Kraken Live (opt-in mainnet)

- **Kraken Live** (`KrakenLiveBroker`): authenticated Spot orders against production
  `api.kraken.com` private REST (`Balance`, `AddOrder` market):
  - `FSB_LIVE_TRADING=1` (explicit opt-in; construction / connect refuse otherwise)
  - `KRAKEN_LIVE_API_KEY` / `KRAKEN_LIVE_API_SECRET` (dedicated; generic
    `KRAKEN_API_*` never used)
  - Demo / futures hosts refused (`demo-futures.kraken.com`, `futures.kraken.com`)
- Settings → Broker Mode: **Kraken Live** (falls back to paper if flag unset)
- Kill-switch: `RiskEngine` + env `FSB_KILL_SWITCH=1` blocks new orders; flatten
  via `close_all` / UI still allowed
- HMAC-SHA512 signature verified against Kraken’s published AddOrder vector

## Opsec

- Secrets only in local `.env` (gitignored); placeholders in `.env.example`
- Prefer trade-only keys, withdraw disabled, IP allowlists, key rotation
- CI must not set `FSB_LIVE_TRADING`; tests mock the live path only
- Never log raw API keys / secrets (`mask_secret` / `redact_mapping`)

## Tests

- `tests/test_kraken_live.py` — signature vector, opt-in refusal, demo refusal,
  kill-switch, mocked mainnet path (no real funds)
