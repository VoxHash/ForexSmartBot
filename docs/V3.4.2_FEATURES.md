# ForexSmartBot 3.4.2 Features

## Paper / sandbox venue paths

- **Venue Paper** (`VenuePaperBroker`): local paper ledger filled at live public
  venue prices (Binance Spot Test Network or Kraken public). No API keys; no
  real funds. Supports connect, market fills → positions, mark-to-market equity,
  close, and `reconnect()`.
- **Binance Sandbox** (`BinanceSandboxBroker`): authenticated HMAC orders against
  **Spot Test Network only** (`testnet.binance.vision`). Production
  `api.binance.com` is refused. Keys from `BINANCE_API_KEY` /
  `BINANCE_API_SECRET` (env only).
- Settings → Broker Mode: **Venue Paper**, **Binance Sandbox**.
- `PaperBroker.reconnect()` and public feed `reconnect()` helpers.

## Opsec

- No mainnet order path in this release.
- Secrets never logged (`venues.secrets` redaction on error bodies).
- See `.env.example` and [MULTI_VENUE_RESEARCH.md](MULTI_VENUE_RESEARCH.md).
