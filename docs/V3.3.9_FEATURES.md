# ForexSmartBot v3.3.9 — Donchian Kernels + Linux aarch64

## Overview

v3.3.9 advances the **native performance core** (`fsb_core` **0.7.0**): Donchian Channel indicator plus Turtle-style breakout equity and parallel period sweeps, and Linux **aarch64** manylinux wheels via cross-compile in `publish-fsb-core.yml`. NumPy fallbacks keep the same APIs when the extension is not built.

## Features

### Donchian Channel (`donchian`)

- Returns `middle`, `upper`, `lower`
- `upper` = highest high over `period`; `lower` = lowest low; `middle` = midpoint
- Requires `period >= 1`
- Pass the same series for high/low when only closes are available

### Donchian breakout equity / sweep

- `equity_donchian_breakout` — long when close breaks above the **prior** upper band; short when close breaks below the **prior** lower band
- `sweep_donchian_breakout` — parallel grid; rows `[period, final_equity, total_return, max_drawdown]`

### Linux aarch64 wheels

- `.github/workflows/publish-fsb-core.yml` adds a `linux-aarch64` job (maturin-action cross-compile from `ubuntu-24.04`, Python 3.10–3.13) alongside existing x86_64 manylinux, Windows, and macOS wheels

## Build

```bash
pip install maturin
cd native/fsb_core && maturin develop --release
python -c "from forexsmartbot.utils.native_indicators import native_status, sweep_donchian_breakout; import numpy as np; print(native_status()); c=np.linspace(1.1,1.2,200); print(sweep_donchian_breakout(c,[10,20,55]).shape)"
```
