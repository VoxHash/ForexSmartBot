# ForexSmartBot v3.3.2 — Q2 Companion Hardening

## Overview

v3.3.2 finishes the remaining Q2 polish items: live CameraX QR pairing, encrypted local companion cache, production cert-pin defaults (env / Gradle), multi-host dashboard polling, and Android companion **0.3.0**.

## Features

### Live CameraX QR (Android 0.3.0)

- `QrScanActivity` + `QrAnalyzer`: CameraX Preview + ImageAnalysis → ZXing (no ML Kit / Play Services)
- CAMERA permission requested at scan time; gallery / paste pairing still available

### Encrypted local cache

- `PairingPrefs` uses `EncryptedSharedPreferences` (AES-256) for session + last portfolio snapshot
- Offline refresh falls back to cached snapshot text
- Legacy plaintext prefs migrate once then clear

### Production cert-pin defaults

- Host: `FSB_COMPANION_CERT_PIN` / `COMPANION_CERT_PIN` → included in pairing QR (`sha256/…`)
- `FSB_PUBLIC_BASE_URL` / `COMPANION_PUBLIC_BASE_URL` for QR `base_url` behind reverse proxies
- Android: `-PFSB_CERT_PINS="host|sha256/…"` BuildConfig field for release store builds

### Multi-host dashboard

- Remote-monitor HTML: add / remove / poll additional monitor base URLs (browser localStorage)
- Shows health, version, and strategy count per host

### F-Droid metadata

- Draft bumped to companion **0.3.0** / versionCode **3** (`mobile/android-companion/metadata/`)
