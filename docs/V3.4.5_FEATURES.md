# ForexSmartBot 3.4.5 Features

## 1inch DEX aggregator execution (dry-run by default)

- **1inch DEX** (`OneInchDexBroker`): Classic Swap quote + swap calldata on
  `api.1inch.com` / `api.1inch.dev` (`swap/v6.1/{chainId}`):
  - Settings → Broker Mode: **1inch DEX**
  - `ONEINCH_API_KEY` (Bearer from Business portal; never commit)
  - Optional `ONEINCH_WALLET_ADDRESS` (public `from` for `/swap`);
    `ONEINCH_CHAIN_ID` (default `1` Ethereum); `ONEINCH_REST_URL`
  - **Dry-run (default)**: `/quote` + `/swap` then local simulated fill —
    **no RPC broadcast**, safe for CI
  - **Broadcast-armed**: only when `FSB_LIVE_TRADING=1` **and**
    `FSB_DEX_BROADCAST=1`; still requires an injected `broadcast_fn` —
    no default private-key signer in-tree
- Kill-switch: `RiskEngine` + env `FSB_KILL_SWITCH=1` blocks new orders;
  flatten via `close_all` still allowed
- Live guard helper: `forexsmartbot.venues.live_guard.dex_broadcast_enabled`

## Opsec

- Secrets only in local `.env` (gitignored); placeholders in `.env.example`
- Never log raw API keys / bearer tokens (`mask_secret` / `redact_mapping`)
- CI must not set `FSB_LIVE_TRADING` or `FSB_DEX_BROADCAST`
- Wallet private keys are **not** read from env by this broker
